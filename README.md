# Учебный Портал (Хогвартс)

## Что это такое
Это сайт для управления учебным процессом. Тут можно вести учет факультетов, групп, курсов и студентов. Еще есть графики, которые показывают, кто больше всего прогуливает (нарушители), какие курсы популярны, и как распределены студенты по факультетам.

## Что умеет сайт
- Добавлять и удалять факультеты.
- Создавать учебные группы и привязывать их к факультетам.
- Добавлять курсы (например, «Травология» или «Зельеварение») с описанием.
- Смотреть красивые графики на странице «Сводки Инквизитора».
- Редактировать данные может только тот, кто состоит в группе «Методист». Обычные студенты могут только смотреть.

## Какие технологии использованы
- Python (язык программирования)
- Django (фреймворк, на котором все работает)
- Django REST Framework (для API)
- PostgreSQL (база данных)
- Gunicorn (сервер, чтобы сайт работал в интернете)
- WhiteNoise (чтобы стили и картинки загружались быстро)
- Tabler (красивый дизайн), HTML, CSS и JavaScript

## Что нужно для запуска
Чтобы запустить проект у себя на компьютере, нужен Python (версия 3.10 или новее) и Git.

## Как запустить (по шагам)
1. Скачайте проект: `git clone https://github.com/ваш_ник/srs7.git`
2. Зайдите в папку: `cd srs7`
3. Создайте виртуальное окружение: `python -m venv venv`
4. Включите его: `venv\Scripts\activate` (если Windows) или `source venv/bin/activate` (если Mac/Linux).
5. Установите нужные библиотеки: `pip install -r requirements.txt`
6. Создайте файл `.env` и впишите туда свои настройки (как в примере `.env.example`).
7. Создайте таблицы в базе: `python manage.py migrate`
8. Создайте админа: `python manage.py createsuperuser`
9. Запустите сервер: `python manage.py runserver`
10. Откройте в браузере: `http://127.0.0.1:8000/`

## Как проверить, что всё работает
- Откройте главную страницу — должна появиться форма входа.
- Войдите под админом, которого создали.
- Зайдите в админку: `http://127.0.0.1:8000/admin/`
- Проверьте API: `http://127.0.0.1:8000/api/course-proposals/` (доступно только после входа).
