# Схема базы данных

В проекте используется несколько связанных моделей, которые описывают учебный процесс.

## Основные модели

### 1. Department (Факультет)
- **Поля**: `id`, `name` (название факультета).
- **Связи**: Один факультет может иметь много курсов и много учебных групп.

### 2. Course (Курс/Дисциплина)
- **Поля**: `id`, `title` (название курса), `description` (описание), `department_id` (внешний ключ на факультет).
- **Связи**: Принадлежит одному факультету. Один курс может быть у многих студентов.

### 3. AcademicGroup (Учебная группа)
- **Поля**: `id`, `name` (название группы), `department_id` (внешний ключ на факультет).
- **Связи**: Принадлежит одному факультету.

### 4. StudentProfile (Профиль студента)
- **Поля**: `id`, `user_id` (ссылка на пользователя), `department_id` (факультет), `academic_group_id` (группа), `relationship_status` (статус отношений).
- **Связи**: Привязан к одному пользователю, одному факультету и одной группе. Имеет связь «многие ко многим» с курсами.

### 5. Violation (Нарушение)
- **Поля**: `id`, `student_id` (кто нарушил), `description` (описание), `date` (дата), `violation_type` (тип нарушения).
- **Связи**: Принадлежит одному студенту (профилю).

## Бизнес-логика (СРС №7)

Для реализации бизнес-процесса «Согласование курса» были добавлены новые модели:

### 6. CourseProposal (Предложение курса)
- **Поля**: `id`, `title`, `description`, `credits` (зачетные единицы), `status` (статус: черновик, на согласовании, согласован, отклонен), `author` (автор), `reviewer` (проверяющий).
- **Связи**: Принадлежит одному автору (пользователю).

### 7. Curriculum (Учебный план)
- **Поля**: `id`, `name`, `academic_year`, `total_credits`, `is_active`.
- **Связи**: Имеет связь «многие ко многим» с предложениями курсов через промежуточную таблицу.

### 8. CurriculumCourseLink (Связь плана и курса)
- **Поля**: `id`, `curriculum_id`, `proposal_id`, `added_at`.
- **Связи**: Промежуточная таблица для связи плана и предложения.

### 9. ProposalEventLog (История событий)
- **Поля**: `id`, `proposal_id`, `action` (действие), `details` (подробности), `performed_by` (кто сделал), `timestamp` (время).
- **Связи**: Принадлежит одному предложению курса.
