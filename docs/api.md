# Описание API 
API нужно для того, чтобы программы могли общаться с нашим сайтом и получать данные. Все запросы работают только после входа в систему.

## 1. Создать новый курс
Что делает: Отправляет на сервер название, описание и количество зачетных единиц для нового курса.
Адрес: POST /api/course-proposals/
Что нужно отправить: JSON с полями title (название), description (описание) и credits (число).
Что вернется: Если всё хорошо, сервер ответит кодом 201 и покажет созданный курс (с его id, статусом "Черновик" и именем автора).
Если ошибка: Сервер скажет "400 Bad Request", если вы забыли заполнить название.

## 2. Изменить статус курса
Что делает: Переводит курс из одного состояния в другое (например, отправить на проверку методисту).
Адрес: PATCH /api/course-proposals/{id}/change-status/
Что нужно отправить: JSON с полем new_status (новый статус).
Что вернется: Если всё хорошо, сервер ответит кодом 200 и покажет обновленный статус (например, "На согласовании").
Если ошибка: Сервер скажет "400 Bad Request", если вы пытаетесь перескочить через шаг (например, из "Черновика" сразу в "Согласован"). Или "403 Forbidden", если у вас нет прав менять статус.

## 3. Посмотреть историю изменений
Что делает: Показывает все события, которые происходили с курсом (кто, когда и что сделал).
Адрес: GET /api/course-proposals/{id}/events/
Что нужно отправить: Ничего, просто открыть ссылку.
Что вернется: Список событий. Например: "Создано" (кем и когда), "Отправлено на проверку" (кем и когда).
